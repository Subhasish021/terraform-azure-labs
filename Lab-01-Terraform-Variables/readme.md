# Lab 01 - Terraform Variables

## Objective

Learn how to declare and use variables in Terraform.

## Topics Covered

- Variable Declaration
- Variable Types
- Default Values
- Description
- Validation
- Sensitive Variables
- Nullable Variables
- Variable Outputs

## Files

- providers.tf
- variables.tf
- main.tf
- output.tf

## Commands Used

terraform init

terraform validate

terraform plan

terraform apply

terraform destroy

## Learning Outcome

By completing this lab, I learned how to declare variables, use different variable types, validate input, and display values using outputs.
